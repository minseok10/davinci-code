# Da Vinci Code

C++로 구현한 다빈치 코드 게임 엔진입니다. 원래 콘솔 기반 게임이었지만, 웹 앱에서 재사용할 수 있도록 게임 규칙과 콘솔 입출력을 분리하는 방향으로 정리했습니다.

## 현재 구현 범위

- 조커를 제외한 0부터 11까지의 흑백 타일 24개를 사용합니다.
- 각 플레이어는 시작 시 4개의 타일을 가집니다.
- 같은 숫자라면 검은색 타일이 흰색 타일보다 앞에 오도록 정렬합니다.
- 자기 턴에는 타일을 하나 뽑은 뒤 상대의 비공개 타일을 추리합니다.
- 정답이면 상대 타일이 공개되고, 같은 턴에서 계속 추리하거나 턴을 넘길 수 있습니다.
- 오답이면 이번 턴에 뽑은 자신의 타일이 공개되고 턴이 넘어갑니다.
- 남은 타일이 없을 때 오답이면 자동으로 왼쪽 타일을 공개하지 않고, 자신의 비공개 타일 중 하나를 선택해 공개해야 합니다.
- 모든 타일이 공개된 플레이어가 패배합니다.

## 주요 파일

```text
.
├── main.cpp        # 임시 콘솔 진입점
├── menus.h/cpp     # 메뉴 및 설명 출력
├── game.h/cpp      # 입출력 없는 DavinciGame 엔진
├── tests.cpp       # 핵심 규칙 테스트
└── Makefile        # 빌드, 실행, 테스트 명령
```

## 빌드

```bash
make
```

## 테스트

```bash
make test
```
