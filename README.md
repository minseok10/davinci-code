# Da Vinci Code

C++로 구현한 콘솔 기반 다빈치 코드 보드게임입니다. 객체지향프로그래밍 Assignment #1 과제로 작성했으며, 구조체와 이중 연결 리스트를 사용해 타일 더미, 컴퓨터 패, 플레이어 패를 직접 관리합니다.

## 프로젝트 개요

이 프로그램은 플레이어와 컴퓨터가 1:1로 다빈치 코드를 진행하는 게임입니다. 숫자 0부터 11까지의 흑백 타일 24개를 사용하며, 조커 타일은 포함하지 않습니다. 각 플레이어는 시작 시 4개의 타일을 가져가고, 자기 차례에는 타일을 하나 뽑은 뒤 상대의 비공개 타일 숫자를 추리합니다.

과제 구현에서 적용한 규칙은 다음과 같습니다.

- 조커 타일은 사용하지 않습니다.
- 컴퓨터가 먼저 턴을 진행합니다.
- 플레이어는 시작 타일과 새로 가져올 타일의 색을 선택할 수 있습니다.
- 같은 숫자라면 검은색 타일이 흰색 타일보다 앞에 오도록 정렬합니다.
- 추리에 성공하면 같은 턴에서 계속 추리합니다.
- 추리에 실패하면 그 턴에 가져온 자신의 타일이 공개됩니다.
- 남은 타일 더미가 없으면 가장 왼쪽의 비공개 타일을 공개합니다.
- 모든 타일이 공개된 플레이어가 패배합니다.

## 주요 구현

- `struct tile`로 타일의 숫자, 색상, 공개 여부, 이전/다음 포인터를 저장합니다.
- `genTile()`에서 24개의 타일을 동적 할당해 초기 타일 더미를 만듭니다.
- `getTile()`에서 타일 더미에서 하나를 뽑아 플레이어 또는 컴퓨터 패의 정렬된 위치에 삽입합니다.
- `pcTurn()`과 `usrTurn()`에서 컴퓨터와 플레이어 턴 흐름을 처리합니다.
- `pcGuess()`는 현재 보이지 않는 후보 숫자 중에서 컴퓨터가 무작위로 추리하도록 구현되어 있습니다.
- `plushTile()`에서 게임 종료 시 동적 할당한 타일 메모리를 해제합니다.

## 파일 구조

```text
.
├── main.cpp        # 메뉴 루프와 프로그램 진입점
├── menus.h/cpp     # 메뉴 및 게임 설명 출력
├── game.h/cpp      # 타일 생성, 이동, 출력, 게임 진행
├── turn.h/cpp      # 컴퓨터/플레이어 턴 및 추리 로직
├── Makefile        # 빌드, 실행, 정리 명령
├── Assignment1.pdf # 과제 명세
└── report.pdf      # 과제 보고서 PDF
```

## 빌드 및 실행

macOS 또는 Linux에서 `g++`와 `make`가 설치되어 있으면 다음 명령으로 빌드할 수 있습니다.

```bash
make
```

실행은 다음 명령을 사용합니다.

```bash
make run
```

빌드 산출물을 삭제하려면 다음 명령을 사용합니다.

```bash
make clean
```

직접 컴파일하려면 다음과 같이 실행할 수도 있습니다.

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp menus.cpp game.cpp turn.cpp -o davinci-code
./davinci-code
```

## 실행 방법

프로그램을 실행하면 메뉴가 표시됩니다.

```text
1. 게임 설명
2. 게임 시작
3. 종료
```

게임 시작 후에는 먼저 플레이어가 가져갈 초기 타일의 흑백 개수를 입력합니다. 예를 들어 검은색 2개, 흰색 2개를 원하면 다음처럼 입력합니다.

```text
2 2
```

플레이어 턴에서는 가져올 타일 색을 선택하고, 추리할 컴퓨터 타일의 위치와 숫자를 입력합니다.

```text
0
3 7
```

위 예시는 검은색 타일을 가져온 뒤, 컴퓨터의 세 번째 타일이 7이라고 추리하는 입력입니다.
